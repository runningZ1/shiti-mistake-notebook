# 管理员小额支付测试页

2026-11-06 用户要求：保存现有默认／管理员账号密码到ENV，提供指定金额或一分钱的真实支付测试页面；自动化测试由用户执行。本次新增本地功能，不部署、不真实付款。

## 页面与业务规则

页面 `/admin/payment-test`，从管理后台侧栏底部进入。仅真实登录管理员可以通过接口创建测试订单和发起付款，普通用户403，未登录401。展示账户、实际扣款说明、金额输入、一分／一角／一元快捷按钮、测试订单记录和结果链接。金额为人民币0.01～100元，最多两位小数，服务端验证并换算成整数分锁定。

测试订单独立标记 purpose=TEST，商品说明明确“不含会员权益”。正式会员仍是99元／30天，测试订单duration_days=0。两种订单共用真实网关协议、签名、持久通知、金额核对、映射绑定、幂等处理和结果页，但测试收款确认后不更新users.paid_ends_at，也不创建会员交付记录。DELIVERED在测试订单表示收款核验完成，页面显示“测试收款已确认”，不显示会员开通。

同一用户、来源、订单用途和金额的待支付单复用；换金额创建独立订单，已创建订单不能改价。重试走原订单号。同金额已付款订单不复用，重新付款需由用户主动再次发起。所有测试付款真实扣款，不自动退款；退款仍须联系支付维护者。

## 开关和联调

`PAYMENT_TEST_ENABLED=true` 只开放管理员测试付款，不要求 `PAYMENT_ENABLED=true`；后者只控制99元会员收费。回调在关闭新下单时继续处理已付款通知。本地两开关保持false；支付侧尚未开放，不发送真实订单。

待维护者开放并确认 source、密钥和登记地址后，把共享密钥只写入后端 `.dev.vars` 的 PAYMENT_SHARED_SECRET，再开启 PAYMENT_TEST_ENABLED。返回页仍为 `https://study.chumenclub.com/payment/result`；回调仍为 `https://study.chumenclub.com/api/payment-callback`。目前本地运行在127.0.0.1:5173，公网回调无法直接访问本地；真实闭环必须先部署获准环境或另行登记可用HTTPS隧道。不能把仅看到支付宝付款链接认定为已支付。
