# 每日错题整理与剪贴打印：开发与验收记录

用户在需求稿交付后要求“好的，开始按照计划开发”，本次按推荐方案实现REQ-DP01～DP06及默认值。REQ-DP07家庭多孩与收费规则继续独立待决。本地实现完成；未提交、推送、迁移原数据库或发布。实体打印与资料不足的场景不计为已验收。

## 已实现

| 需求 | 实际行为与代码 |
|---|---|
| DP01 按天整理 | 工作台今天、单日与包含首尾的日期区间，按北京时间归档日过滤，与月份互斥；URL恢复日期/学科/搜索，非法区间保留原结果。`app/dashboard.tsx`、`lib/mistake-dates.ts`及列表API |
| DP02 选题排序 | 按日全选、取消、整日整理、打印清单移除及上移/下移；筛选改变清空选择，空列表仍显示清空提示；生成前查库核对存在性 |
| DP03 本人错因 | `mistakes.reflection`纯文本，trim后1000个Unicode码点；显式保存、错误保留、清空、刷新持久化；与AI解析分开；详情关闭和打印处理未保存内容 |
| DP04 打印设置 | `app/mistake-printing.tsx`及CSS提供桌面/手机面板、12/14pt、剪贴/练习单、三种错因输出、答案另页开关、已有相似题开关、重新下载 |
| DP05 原题与生成 | `lib/mistake-docx.ts`生成A4/20mm剪贴块、裁剪线和错因留白；短文本题保持整体，长题表头重复；原图与公式保留。合法题目区域的剪贴版、WEBP或超过30题使用浏览器路径，其他优先原生服务端附件下载 |
| DP06 权限与失败 | 所有读写限定当前账号；混入不可访问ID的批量导出整体失败；到期后可编辑旧题但AI仍受限；停用写入触发器保留。附件在独立下载框架请求，错误不替换工作台页面 |

共享选项集中在`lib/mistake-print-options.ts`，客户端和两个Word接口使用相同契约。无选项旧Word请求继续使用原练习单；旧举一反三、单元卷与账号规则保留。

## 未完成的实测与上线条件

- 只有1道真实错题，未用伪造题目凑数；跨真实多批次、多题移动、超过30题与真实题目区域裁剪尚无实际批量运行证据。已有真实照片转换为WEBP的副本已验证浏览器生成路径，未改变题干和题目ID。相关生成器与选项行为已由现有文档验证脚本覆盖，不能代替真机实测。
- 本机Word自动化重新分页/导出PDF超时；桌面自动化工具另报DACL权限错误，未修改操作系统权限。Word打开成功不等于排版纸面已验收；需在用户实际Word/WPS和打印机核对长题、原图、裁剪线与字号。
- 原图内字的大小不由正文字号控制；超过单页的整图按比例保留完整内容并在文件中提示核对，未承诺自动去笔迹或重排原图。
- 发布前备份原数据库和对象存储、应用0005迁移，按原有部署流程执行，并核对历史图片键的既有不一致。没有发布授权，本次不执行这些操作。

## 使用方式

进入“我的错题本”→今天或指定日期/区间→按日全选或逐题勾选→详情填写并保存“我的错因”→“整理与打印”→调整清单与选项→下载Word→用Word/WPS打印剪贴。也可全部留白，让学生在纸上填写错因。
