# 使用流程 Review 与记录恢复修复

## 结论

原图与 OCR 已存储，但完整分析只存在 React 内存中；工作台将“上传/分析记录”错误等同于“已确认错题”。零错题、全部待核对的作业没有历史入口，结果页也没有可恢复的 URL。此前只验证接口和当次页面返回，没有覆盖刷新与历史查询，产品流程验收不充分。

本次新增完整分析持久化、用户级历史列表/详情、稳定记录链接、失败保留与幂等重试，独立展示原图、OCR、判题结论与当前归档状态。原有两条真实上传记录已找回，升级前未保存的判题结论不补造。

## 发现与处置

| 级别 | 问题与实际影响 | 处置 |
| --- | --- | --- |
| P0 | 分析保存在 `useState`，刷新后丢失完整报告 | `uploads.analysis_result` 保存摘要、逐题结论和待核对说明；详情 API 从数据库恢复，错题从实时业务表读取 |
| P0 | 工作台只列出错题，全部待核对或零错题会被表现为“从未上传” | 新增独立“分析记录”和工作台“最近分析”，按真实上传列出，不依赖错题数 |
| P1 | 结果页与首页共用无状态 URL，浏览器刷新/返回无法恢复记录 | `?view=results&upload=<id>`；前进、后退和刷新通过鉴权详情接口读取 |
| P1 | 上游失败后删除原图，也没有业务记录 | 原图写入后先建上传记录，OCR 成功后单独保存；外部分析失败保留资料和中文原因，允许从原记录继续 |
| P1 | 重复重试会重复计费、重复归档，处理中没有可见状态 | 行锁领取任务、processing/completed/failed 状态、尝试 ID；并发返回 409，已完成直接返回保存结果；15 分钟未完成任务允许重试，旧尝试不能覆盖新尝试 |
| P1 | 待核对只有内部题号，没有题干/作答/原图，无法核查 | 详情展示真实 OCR 题干、选项、作答、照片中的参考答案及原图；明确待核对不等于全对 |
| P1 | 页面“批改完成/没有错题”误导为学习任务已完成 | 区分“分析已保存 · 有题目待核对”“分析未完成”“历史作业”；分析判错数与当前归档数分开，移除错题后不改写历史判题 |
| P1 | 练习卷/作文报告已保存，但当前打开的详情未定位到 URL | 为已保存详情增加 paper/essay 参数与恢复逻辑；作文离开时提醒未保存草稿，正在处理时阻止侧栏离开 |
| P2 | 历史加载失败可能混同于空数据 | 新列表/详情有独立 loading、error、empty、重试状态，分页显示实际总数；不把数据库故障当空列表 |

- 追加 `0007_upload_analysis_history.sql`，未修改任何已执行迁移。保存 analysis_result、状态、错误、启动时间与尝试 ID；同步 Drizzle PostgreSQL 元数据。
- 本地迁移前备份：`work/analysis-history-review/shiti-before-0007.dump`，58,068 字节。已执行本地迁移，生产未操作。
- 旧记录仍展示原图、原始 OCR 和现存错题，不凭 OCR 推算过去的判题结论。重新分析须用户主动点击，读取历史不调用模型；旧记录已有归档错题时禁止直接重分析覆盖。
- 历史/详情/原图按当前账号查询。体验到期仍可读取历史；重试走现有 AI 权益校验。匿名返回 401，其他账号详情与原图返回 404，重试拒绝异源请求。
- 新请求只在建立上传记录之前出错时清理未归档对象；建立记录之后的分析故障保留原图和已识别文字。账号/后台删除仍沿用现有真实清理流程。

## 实测

1. 真实 PostgreSQL、R2、百度 OCR 和 DeepSeek，没有模拟业务响应。
2. 浏览器找回原先的两条公开照片记录；原图和识别文字可见。旧记录详情刷新后 URL 和资料保持。
3. 使用隔离本地测试进程的无效模型凭据制造真实 401 上游拒绝：应用返回 503 和 uploadId，记录为 failed，保留已成功的 OCR；原图回读字节与下载文件一致。真实主配置未改为无效密钥。
4. 在正常主进程重试此真实失败记录：两次并发请求分别 200/409；完成后再次调用返回相同保存结果，独立 GET 恢复完全相同的 analysis。其他真实账号读取详情和原图均为 404。
5. 用户当前浏览器中的旧记录通过已保存 OCR 继续分析，完整结果已持久化。完整结果经刷新、新开标签页和工作台历史点击后均成功恢复；截图为 `work/analysis-history-review/result-after-refresh.png` 与 `history-restored.png`。
6. 类型检查、隔离构建、定向 ESLint（无错误）、19 项现有相关回归通过。真实 HTTP 流程结果位于 `work/analysis-history-review/lifecycle-result.json`。临时负向测试进程已停止，包含复制凭据的测试配置已移除。

练习卷和作文详情恢复目前覆盖源码、类型和构建；本轮没有为这两个功能额外生成新的学习内容。支付、正式会员收款和线上部署未执行。

## 仍需产品补齐的流程

- 待核对现在可找回并对照原图查看，但尚没有“逐题编辑确认 OCR → 重新判题 → 明确确认归档”的完整操作闭环；固定置信度和配图保护使本批照片全部待核对。不能据此宣称自动判题准确性或学习闭环已通过验收。下一步应设计可追溯的人工确认，不应直接降低阈值制造错题。
- 作文尚未生成报告的照片/编辑稿仍属临时草稿，离开有提醒，不具备跨设备草稿恢复。练习答案沿用现有 sessionStorage 草稿策略；已保存的练习与报告可从服务器恢复。
- 当前分析处理仍是请求内执行，刷新断连后的服务器任务能否继续受运行环境影响；任务状态持久化，15 分钟超时后可重试。要做到断网/关页后保证持续处理，后续需要持久任务队列和后台执行。
