# 后台管理流程完善验收

日期：2026-10-31。

规格：[后台管理流程完善](../../../specs/changes/admin-management.md)。

## 实现

后台栏目使用网址参数恢复位置；用户、上传批次、学科与错题查询相互连接。用户列表提供使用权限筛选、注册与登录时间排序、错题数量排序和清除筛选。学科下拉包含数据库现有名称。账号删除输入用户名确认，并展示清理范围。加载、空结果、错误重试、辅助文字和表格显示使用统一规则。

账号及学习资料使用 PostgreSQL，通过标准 `pg` Pool、参数化 SQL 和事务访问。数据库使用 text 标识、timestamptz 时间、jsonb 结构化字段，账号 ID、密码及既有资料保持原值。接口时间保持 ISO 字符串。

账号多字段修改在事务内通过单次 UPDATE 提交，期限延长基于数据库执行时的当前值。修改及删除流程获取共用 advisory 事务锁，再锁定目标账号，保护最后一个启用管理员。账号标记删除后禁止重新启用或修改。

六张业务表的 INSERT、UPDATE 触发器通过 `FOR SHARE` 锁定所属账号，检查账号状态及删除标记。错题通过上传批次和账号的复合外键防止跨账号关联。图片内容上传前保存 multipart 标识；账号删除先停用、终止全部已登记上传，再删除图片，最后事务清理数据库，失败时保留索引供重试。

- 验证脚本从 `public` 复制三个真实账号、一份真实上传和一道真实错题到专用 schema，未生成示例业务资料，未修改 `public` 资料。

- 真实账号及其关联资料的数据库删除事务成功，验证后执行 ROLLBACK。
