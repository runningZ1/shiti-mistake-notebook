# 移动端 H5 适配优化（2026-11-12）

## 目标与范围

保留拾题现有浅色、蓝紫主操作的视觉体系，优化手机上的学习工作台、档案管理、作业核对、错题本、学习工具和打印设置。兼容 320px 小屏，保留桌面布局与全部现有学习功能。本次不修改数据库、OCR、AI、支付逻辑。初次交付仅本地修改；用户随后明确授权提交、推送和部署，发布结果另记。

## 问题与修改

| 问题 | 修改 |
| --- | --- |
| 顶部栏将面包屑、档案选择、管理和拍照入口挤在一行 | 手机拆为导航行、档案操作行；中等宽度允许换行 |
| 档案管理的编辑入口留在顶部，表单单独绝对定位 | 将管理操作、表单与说明放入同一有宽高上限的弹出面板 |
| 部分表单字体偏小、按钮难点 | 手机学习表单使用 16px 字体和至少 44px 高度；后台表单和打印设置同步调整 |
| 作业核对字段、日期筛选和多操作按钮在小屏拥挤 | 上传元数据改为单列；筛选与操作允许换行；题图裁剪预览去除额外水平留白 |
| 错题详情通过 portal 渲染，未继承工作台标签换行规则 | 为详情面板单独定义标签、题头与操作区换行规则，解决真实 320px 页面中的水平滚动 |
| 打印面板关闭按钮较小，长面板滚动与安全区不足 | 关闭与排序操作至少 44px；内容独立滚动，头尾不压缩，按安全区限制高度 |
| 手机菜单打开后切至桌面，仍可能保留滚动锁 | 监听桌面断点，关闭手机菜单并由已有清理逻辑恢复页面滚动 |
| viewport 未声明全面屏安全区 | 添加 viewport-fit=cover，保留正常页面缩放，补充顶部、侧边与底部安全区间距 |

## 验证结果

- TypeScript：`npx tsc --noEmit` 通过。
- ESLint：`npm run lint` 通过，0 错误、11 条现有告警（图片、导航和未使用变量）。
- 构建：已有预览占用原 `dist/client`，原目录构建报 EBUSY；复制当前源码到被忽略的 `work/mobile-preview`，复用 node_modules 后完成独立生产构建。最后一批 CSS 修复后再次构建通过。
- Impeccable 机械检测：本次涉及的 8 个源码文件检查返回 `[]`。
- Chrome 内置 Computer Use：运行实际 Workers 构建，使用既有隔离 schema 中的真实作业副本和既有登录会话验证。仅本机回环代理注入会话，凭据未写入源码和文档；未生成虚构学生作答。
- 工作台宽度：320、375、430、768、1024、1440px，页面 scrollWidth 与 clientWidth 相等，上传字段未越出视口。
- 320px 页面：错题本、练习、知识图谱、作文入口、作业列表、真实作业详情均未发现整页横向溢出；作业详情实际渲染了 3 个题目编辑器。
- 320px 弹层：错题详情 clientWidth/scrollWidth 均为 285px；打印面板均为 300px，关闭按钮高 44px；档案面板在 375px 下从 x=16px 到 x=296px，未越界。
- 菜单断点：手机打开侧栏后切换到 1024px，sidebar.open=false、body.style.overflow 恢复为空。
- 320px 公开页面：首页、注册、定价均无整页水平溢出；注册的 5 个输入框均为 16px 字体。
- 检查结束后恢复浏览器默认视口。

- 管理后台的此次修改限于样式与静态检查，未进行管理员登录后的浏览器验收。
- 作文页验证上传入口与空状态布局；没有编造作文报告验证历史报告布局。
- 未触发新的 OCR、AI、付款或 Word 导出；纸张打印效果不在本次范围。
- 验证临时源码、运行设置与日志位于被 Git 忽略的 work 目录。原有其他预览进程未终止。
